# JP Recomposição — Portal de Recomposição da Aprendizagem

Ambiente público de atividades de recomposição da aprendizagem e Busca Ativa Escolar da Escola Estadual João Paulo I, em Paranaíta, MT.

## Acesso

- Página inicial: `index.html`
- Componentes: `recomposicao.html`
- Busca Ativa: `busca-ativa.html`
- Matemática: `componentes/matematica.html`
- Língua Portuguesa: `componentes/lingua-portuguesa.html`

Este repositório contém somente arquivos públicos de um site estático destinado a estudantes e à comunidade escolar.

**Não há autenticação individual nem banco de dados nesta versão.** Os relatórios locais exportados pelos estudantes não são armazenados no GitHub. Não publique dados pessoais, senhas, PEIs, notas ou registros escolares aqui.

Para publicar: GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
